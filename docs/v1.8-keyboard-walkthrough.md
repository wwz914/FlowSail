## 组件级测试

- Tab 序列（画布 → 连线 → 节点）与 `tabIndex` / `role` / `aria-label`；

## 未覆盖 / 限制

- 只做了 Chrome + 键盘走查，没有多浏览器 / 多读屏器矩阵；
- 对比度只抽查了画布节点的主文字与背景，未逐项审计全部面板；
- 焦点样式依赖 `:focus-visible`，Safari / Firefox 的细节表现未纳入本记录。
